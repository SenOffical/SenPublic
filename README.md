## 功能介绍

Sen 是运行在支付宝内的一款自动化辅助模块，帮助用户自动完成各类日常公益与游戏任务，减少重复操作。

### 🌳 蚂蚁森林
- 自动收取自己的绿色能量
- 自动收取好友的绿色能量
- 自动给好友浇水
- 合种树自动管理
- 森林道具自动使用（加速卡、时光加速器等）
- 森林抽抽乐自动参与

### 🐔 蚂蚁庄园
- 自动投喂小鸡饲料
- 自动驱赶偷吃的小鸡
- 自动雇佣/解雇小鸡
- 庄园抽抽乐自动参与
- 小鸡家族任务自动管理
- 庄园道具自动使用

### 🌊 蚂蚁海洋
- 海洋日常任务自动完成
- 海洋状态自动维护

### 🏃 蚂蚁运动
- 运动任务自动完成
- 运动宝箱自动开启
- 走路步数相关任务

### 🏬 蚂蚁摊位
- 自动摆摊
- 自动收摊
- 自动请走占用摊位的用户

### 👑 蚂蚁会员
- 会员日常任务自动完成
- 会员积分相关操作

### 🍎 蚂蚁果园
- 果园日常任务自动完成
- 果树种植与管理

### 🤝 蚂蚁合种
- 合种树木自动管理
- 合种任务自动完成

### 🦤 蚂蚁嘟嘟鸟
- 嘟嘟鸟日常任务自动完成

### 🌿 生态保护
- 生态保护日常任务自动完成

### 💹 绿色金融
- 绿色金融任务自动完成
- 绿色能量相关金融操作

### 🏞 保护地
- 保护地任务自动完成

### 🧠 AI 答题
- AI 辅助完成蚂蚁庄园/森林等模块的答题任务
- 支持多种答题场景

### 🏠 好家无忧
- 好家无忧任务自动完成

### 🐟 鱼塘
- 鱼塘日常任务自动完成

### 🎮 支付宝游戏
- 支付宝内置小游戏任务自动完成
- 支持多款游戏场景

## 高级功能

- **智能蹲点**：在能量成熟、小鸡进食结束、宝箱开启等时机精准执行，不错过重要时间点
- **任务定时调度**：支持自定义执行间隔，灵活安排日常任务执行时间
- **执行统计**：提供任务执行记录、能量收取统计等数据可视化看板
- **AI 辅助**：内置 AI 答题能力，智能应对各类答题场景
- **通知提醒**：任务执行完成后发送通知，随时了解执行状态
